🍜 FoodNanny

A full-featured, enterprise-grade Multi-Restaurant Food Delivery Platform with a Progressive Web App (PWA) customer frontend, a powerful admin dashboard, restaurant management, real-time delivery tracking, and an integrated AI assistant — all built on a modern Laravel + Vue 3 stack.

Laravel 12 Vue 3 PHP 8.2+ Multi-Restaurant PWA AI-Powered Real-time 16 Payment Gateways 8 SMS Gateways OpenAI

🏠 Overview

FoodNanny is a production-ready SaaS food delivery solution designed for restaurant chains, aggregators, and delivery startups. It provides everything from customer ordering to restaurant management, delivery dispatch, payment processing, and AI-powered content generation — all in a single cohesive application.

🖥️ Backend Architecture

The backend follows a Service Layer pattern where controllers are thin and delegate all business logic to dedicated service classes. This promotes testability, reusability, and clean code.

Design Patterns Used

🏗️Service Layer
  • 140+ service classes
  • Controllers stay thin
  • Business logic isolated
  • Easily unit-testable
👁️Observer Pattern
  • 12 model observers
  • Hooks into Eloquent events
  • Auto side-effects on create/update
  • Clean model lifecycle handling
📡Event/Listener
  • 15 broadcast events
  • Decoupled side effects
  • Email, SMS, push on events
  • Queued listeners
🏭Factory / Strategy
  • AI agent factory (AiService)
  • Payment gateway abstraction
  • SMS gateway abstraction
  • Storage abstraction

🤖 AI Assistant

FoodNanny includes a modular AI system built on the addon-ai branch. It uses an abstract factory pattern (AiService) that dynamically loads AI provider agents, starting with OpenAI.

ℹ️ The AI system is designed for extensibility — adding a new AI provider (e.g., Gemini, Claude) requires creating a new agent class under app/Http/AiAgents/Agents/ and registering it in the database.

AI Architecture

AiService (Factory)
  └── agent('Openai', ...) → new App\Http\AiAgents\Agents\Openai($args)
           ├── status()       → Check AI agent availability
           ├── name()         → Generate product names
           ├── description()  → Generate product descriptions
           └── message()      → General chat/message generation

Database:
  ai_agents          → Provider configs (model, endpoint, key)
  ai_chat_histories  → Conversation logs per user
  ai_usage_logs      → API token usage tracking

AI Capabilities

  • AI-generated product/item names for restaurants
  • AI-generated product descriptions
  • Chat message generation
  • Usage logging for cost monitoring
  • Chat history persistence per user
  • Per-agent gateway configuration (API key, model, etc.)

AI-Related Traits

The HasAiPrompt trait can be added to any model to enable AI content generation capabilities for that resource.

🚀 Installation

✅ FoodNanny includes a built-in Installation Wizard accessible at /install that guides through all setup steps.

Wizard Steps

  • System requirements check (PHP version, extensions)
  • File permission verification
  • License acceptance
  • Site configuration (name, logo, colors)
  • Database credentials and migration run
  • Admin account creation

Manual Installation

# 1. Clone repository
git clone <repo-url> foodnanny && cd foodnanny

# 2. Install PHP dependencies
composer install

# 3. Install JS dependencies
npm install

# 4. Copy and configure environment
cp .env.example .env
php artisan key:generate

# 5. Run database migrations and seeders
php artisan migrate --seed

# 6. Build frontend assets
npm run build

# 7. Set file permissions
chmod -R 775 storage bootstrap/cache

# 8. Start development server
composer dev   # Runs artisan serve + queue + vite + pail

Post-Installation Checklist

  • Configure payment gateways in admin panel → Settings → Payment
  • Configure SMS gateways in admin panel → Settings → SMS
  • Set OpenAI API key in admin panel → Settings → AI
  • Configure Firebase for push notifications
  • Set Google Maps API key (VITE_GOOGLE_MAP_KEY)
  • Configure AWS S3 or local storage
  • Set up Pusher credentials for real-time features
  • Configure Mailer Send for email delivery
  • Enable PWA in admin panel → Settings → PWA
  • Set up HTTPS SSL certificate for production
