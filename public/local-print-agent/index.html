Local Print Agent

Cloud servers cannot reach restaurant LAN printers (192.168.x.x). Run this agent on the POS PC next to the printer (India store PC). Keep the window open while using POS. Printing works from that PC only — not from another country.

  1. On the store POS computer (same Wi‑Fi as the TVS printer), download the agent below.
  2. Right‑click Start-LocalPrintAgent.ps1 → Run with PowerShell. Keep that black window open.
  3. Open POS on this same computer and place a test order (Confirm & Print).
  4. Optional: click Check Agent below — it must say Ready.
Download Windows Print Agent (.ps1) Download Python agent (Mac / Linux / Windows)
Important: If you open POS from Pakistan (or any remote PC), the browser cannot reach the store printer. Orders must be confirmed on the store PC where this agent is running.

After the agent starts, go back to POS and use Test Print in Printer Settings.
