Local Print Agent (no Chrome popup)

Your website runs on the internet. The kitchen printer is on the restaurant Wi‑Fi (192.168.x.x). The cloud server cannot reach that printer, so Direct Print must use a small agent on the POS Windows PC.

One-time setup on POS PC

  1. Download Start-LocalPrintAgent.ps1 to the Desktop.
  2. Right‑click → Run with PowerShell (keep the black window open).
  3. If Windows asks about firewall, allow access on private networks.
  4. In Printer Settings:
    • Computer IPv4 = this POS PC IP (e.g. 192.168.1.103)
    • Printer IP = the TVS / thermal printer IP from a self‑test page — not the PC IP (unless the printer truly shares that address)
    • Port 9100, Printing Choice = Direct Print
  5. Click Test Print below or in Printer Settings.
If Printer IP and Computer IP are the same, that usually means the thermal printer IP was never set. Print a network config / self‑test page from the TVS printer and use that IP.

Why the print dialog still appeared

When Direct Print failed from the server, the app used to fall back to the browser print window (often showing AnyDesk Printer). That fallback is removed — jobs now go through this local agent instead, with no popup.
